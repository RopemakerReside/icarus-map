## 🧩 About

**ICARUS Map Overlay** is a comprehensive map tool for ICARUS featuring resource tracker, loot radar, extraction point markers, cave locator, and co-op sync.

Based on popular tools like **Icarus Map**, **Survival Map**, and **ICARUS Companion**.

---

## ✨ Features

### 🗺️ Map & Navigation
- Resource Tracker — highlight ore, plants, and animal spawns on the map
- Loot Radar — detect nearby containers and dropped items
- Extraction Point Markers — always know where to evacuate
- Cave Locator — find cave entrances and underground resources
- Waypoint System — set custom markers for your base or mining routes

### 🎯 Gameplay Assistance
- Co-op Sync — share map markers with your squad
- Storm Tracker — real-time storm position and timer
- Mission Overlay — show active objectives and timers
- Enemy Radar — detect hostile wildlife and players

### ⚙️ Interface & Customization
- Overlay Menu — toggle features with a hotkey
- Config Profiles — save and load different setups
- Adjustable Transparency — blend the map into your HUD
